隐私权政策 (Privacy Policy)

最后更新日期：2023年10月

本隐私权政策适用于名为“票票助手 (NOL & MG Auto Ticket)”（以下简称“本扩展”）的 Chrome 浏览器扩展程序。

1. 我们收集的信息

本扩展程序不收集、不存储、也不向任何第三方服务器传输您的任何个人数据。

您的所有配置信息（包括但不限于：演出ID、目标区域、购票数量、手机号码、支付方式、以及第三方通知服务的 Bot ID）均仅保存在您本地浏览器的安全存储空间（chrome.storage.local）中，扩展作者及任何第三方均无法访问。

2. 权限使用说明

  • 存储权限 (storage)： 仅用于在本地保存您的抢票配置参数。
  • 网站访问权限 (tkglobal.melon.com/world.nol.com)： 仅用于在目标购票页面执行辅助选座和表单自动填写操作。
  • 网络请求权限 (qmsg.zendee.cn)： 仅当您在配置中主动填写了 Qmsg 酱 API Token 时，用于向您自己的账号发送抢票结果通知。我们不会记录您的 Token。

3. 数据共享与披露

由于本扩展不收集任何数据，因此我们不会与任何第三方共享、出售或披露您的信息。

4. 联系方式

如果您对本隐私权政策有任何疑问，请通过 [你的邮箱地址或 GitHub Issues 链接] 与我们联系。
